## Быстрый старт

**Скачать:** зелёная кнопка **Code → Download ZIP** вверху страницы или раздел [Releases](https://github.com/partfonia/FPCastor/releases).

**Windows**
1. Установите Python 3.11+ с [python.org](https://www.python.org/downloads/). При установке отметьте галочку **Add python.exe to PATH**.
2. Запустите `install.bat`, потом `start.bat`.

**Linux / macOS**
```bash
chmod +x install.sh && ./install.sh
./start.sh
```

**Docker**
```bash
docker compose up -d --build
docker compose logs -f   # здесь будет пароль веб-панели
```

При первом запуске откроется мастер настройки. Он спросит golden_key FunPay, token Playerok, токен Telegram-бота, прокси и настройки мини-аппа. Без мастера тоже можно: `python main.py` сам установит недостающие пакеты.

| Команда | Что делает |
|---|---|
| `python main.py` | меню запуска (через 10 секунд бот стартует сам) |
| `python main.py --setup` | мастер настройки |
| `python main.py --no-dialog` | запуск без меню — для сервисов и Docker |
| `python main.py --install-service` | автозапуск: systemd на Linux или автозагрузка Windows |

## Где взять ключи
- **FunPay `golden_key`**: войдите на funpay.com → F12 → Application → Cookies → `golden_key`.
- **Playerok `token`**: войдите на playerok.com → F12 → Application → Cookies → `token`.
- **Telegram-бот**: создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен. Потом напишите своему боту `/login ПАРОЛЬ`.

## Если что-то не получилось
- **Playerok не подключается.** Нужен Python 3.11 или новее (лучше 3.12) и интернет при первом запуске: бот докачает три небольших пакета. Git не нужен — библиотека Playerok уже встроена в проект. Подробности ошибок установки — в `castor_data/logs/install.log`.
- **«Сайт не отвечает».** FunPay, Playerok или Telegram недоступны с вашего интернета — включите VPN или укажите прокси (мастер предложит это сам).
- **«Ключ не подошёл».** Ключ устарел: выйдите и снова войдите на сайте, скопируйте golden_key или token заново.
- **Настроить заново:** `python main.py --setup` (или пункт 2 в меню при запуске).

## Приложение (мини-апп) не открывается?
Бот сам получает бесплатный HTTPS-адрес и **сам выбирает рабочий способ**:
1. Cloudflare (через TCP — работает, даже когда провайдер режет UDP/QUIC);
2. localhost.run по ssh;
3. localhost.run по ssh **через прокси Telegram-бота** — если у провайдера закрыт доступ к сервисам туннелей;
4. Pinggy по ssh на порт 443.

Каждый адрес проверяется снаружи, и кнопка «📱 Панель» ставится только на рабочий. Раз в 2 минуты бот перепроверяет адрес и при сбое переключается на следующий способ.
Экран «📱 Приложение» (`/app`) показывает, какой способ работает, последние попытки и причины; там же можно выбрать способ вручную или нажать «🔁 Другой способ».
Для ssh-способов нужен клиент OpenSSH — в Windows 10/11 он встроен.

## Свой Telegram-бот и прокси
- Бота можно сменить в любой момент, перезапускать ничего не нужно: мини-апп → «Ещё» → «Бот и прокси», в Telegram команда `/proxy` → «Сменить бота», в консоли пункт меню 6.
- Прокси: список из нескольких штук, бот берёт первый рабочий. Есть кнопки «Проверить все» и «Использовать» для конкретного прокси. Изменения применяются сразу.
- **Автопереключение**: раз в минуту бот проверяет связь с Telegram. Если прокси перестал отвечать, бот сам переходит на следующий рабочий и пишет вам об этом.
- **Любой формат.** Вставляйте прокси так, как дал продавец, — бот сам приведёт запись к нужному виду: `ip:порт:логин:пароль`, `логин:пароль@ip:порт`, `ip:порт@логин:пароль`, `логин:пароль:ip:порт`, `socks5://…`, `http://…`, через пробелы или блоком «IP / Порт / Логин / Пароль». Тип подключения (HTTP или SOCKS5) бот подбирает сам и запоминает подошедший. MTProto-прокси Bot API не поддерживает.
- **Тип прокси**: IPv4, IPv4 Shared или IPv6 — выбирается при добавлении (или кнопкой 🏷 в Telegram, списком в мини-аппе). По умолчанию «авто»: IPv6-адрес бот узнаёт сам, а при проверке смотрит, через какой протокол прокси выходит в интернет.
- **IPv6-прокси** открывают только сайты, которые работают по IPv6. Telegram подходит. Если сайт через IPv6 не открылся, бот прямо скажет, что для него нужен IPv4 или IPv4 Shared. Для IPv6 бот всегда ищет адрес сайта на стороне прокси (SOCKS5 с удалённым DNS), иначе соединение не установится.
- У FunPay и Playerok свои прокси, они задаются в настройках каждой площадки.

## Мини-апп
Telegram открывает мини-апп только по HTTPS-адресу. Есть два варианта:
1. Включите туннель **Cloudflare** («Ещё» → «Админы и доступ» → «Туннель» или в мастере настройки). Бот сам скачает cloudflared, получит адрес `*.trycloudflare.com` и поставит кнопку «Панель» в меню бота.
2. Укажите свой домен с HTTPS (через nginx/caddy на порт 8765) в поле «Публичный HTTPS-адрес».

Из браузера панель открывается по адресу `http://IP:8765` и паролю веб-панели.

## Возможности

**Обе площадки**
- автовыдача из файлов (с учётом количества и нескольких строк на единицу) или фиксированным текстом;
- автоответы на команды: несколько триггеров, точное совпадение или по слову, случайные варианты ответа через `|||`;
- приветствие новых чатов, сообщение после оплаты, благодарность за подтверждение;
- рабочее время и режим отпуска (с датой окончания, можно остановить выдачу);
- чёрный список;
- постоянные покупатели: база покупателей, сумма покупок, заметки, отдельное приветствие при повторном заказе;
- напоминание подтвердить заказ через N часов;
- антифлуд: защищает от зацикливания с чужими ботами.

**FunPay**: вечный онлайн, автоподнятие лотов (бот сам ждёт, когда FunPay разрешит поднять снова), автоответы на отзывы по количеству звёзд, возврат денег кнопкой, автовозврат, если товар закончился.

**Playerok**: отметка «товар отправлен» после выдачи, уведомления о сделках, отзывах, проблемах и возвратах.

**Telegram**: уведомления (каждый тип включается отдельно, можно слать в группы и каналы), ответ покупателю прямо из уведомления, шаблоны ответов, итоги дня, предупреждение, когда товар заканчивается, бекап одной кнопкой.

**Мини-апп**: выручка обеих площадок в шапке, график за 14 дней, чаты с перепиской и ответами, поиск по заказам, покупатели, редактор правил и товаров, проверка, какое правило сработает, все настройки, плагины, бекапы, логи, правка конфига в JSON.

**Прочее**: вебхуки (Discord и свой сервер), ежедневный автобекап, горячее применение настроек.


## Возможности версии 2.1

### Несколько аккаунтов
Можно подключить сколько угодно аккаунтов FunPay и Playerok: в мини-аппе «Ещё» → FunPay / Playerok → «Добавить аккаунт», в Telegram «🔵 FunPay» → «➕ Добавить аккаунт» или в мастере настройки. Аккаунты подключаются и отключаются сразу, перезапуск не нужен. У каждого аккаунта свой ключ, прокси, название и переключатели автовыдачи и автоподнятия. Тексты и автоответы общие для площадки. В уведомлениях видно, с какого аккаунта пришёл заказ. Правило выдачи можно ограничить отдельными аккаунтами. Старый конфиг с одним аккаунтом переносится автоматически.

### Роли помощников
| Роль | Что может |
|---|---|
| Владелец | всё, включая ключи, вывод средств, команду и бекапы |
| Администратор | все настройки, возвраты, финансы, плагины, прокси; без ключей, вывода и управления командой |
| Менеджер | чаты и ответы покупателям, заказы **без сумм**, пополнение товаров (только добавление), заметки о покупателях |

Помощника добавляют через приглашение: «👨‍💼 Команда» → «Пригласить». Бот выдаёт одноразовую ссылку на 24 часа. Права проверяются на сервере для каждой кнопки и каждого запроса, а не только скрываются в интерфейсе. Пароль `/login` работает только для самого первого владельца. Вход в веб-панель по паролю даёт права владельца, поэтому пароль должен быть сложным.

### Учёт прибыли
Прибыль = сумма заказа − комиссия площадки − себестоимость − расходы за период.
- **Себестоимость** задаётся за единицу в правиле выдачи. У поставщика бот может брать реальную цену закупки из ответа. Для любого заказа её можно поправить вручную: «Продажи» → заказ.
- **Комиссия площадки** в процентах указывается в «Финансы», если на баланс приходит меньше суммы заказа.
- **Расходы** (реклама, оптовые закупки) добавляются в «Финансы».
- **Возвраты** исключаются из выручки автоматически.
- Отчёты показывают прибыль по периодам, площадкам, аккаунтам и товарам. В итогах дня и на графике тоже видна прибыль.

### Лоты без товара
Привяжите к правилу выдачи лоты FunPay: «Выдача» → правило → «Привязать лоты». Бот сам предложит подходящие по ключевым словам. Когда файл товаров опустеет, бот, в зависимости от режима в «Функциях»:
- **спросит** в Telegram «Скрыть лоты?» с кнопками (режим по умолчанию);
- **скроет** лоты сразу;
- **только сообщит**.

После пополнения файла бот предложит включить лоты обратно или включит их сам. После каждого изменения бот перечитывает лот и проверяет, что FunPay его действительно сохранил. Для Playerok — только уведомление.

### API поставщика
«Ещё» → «Поставщики»: адрес, метод, заголовки с ключом, шаблон тела запроса и путь к товару в ответе (например, `data.codes`). Подходит любой сервис с HTTP API. В правиле выдачи выберите режим «Купить у поставщика». Защита:
- если связь оборвалась посреди покупки, бот **не покупает повторно**: заказ попадает в список «Ждут проверки», а вы получаете уведомление;
- можно указать запасной файл товаров на случай, если поставщик не ответил;
- кнопка «Показать запрос» показывает, что уйдёт поставщику, ничего не отправляя. «Тестовая покупка» — настоящая покупка.

### Автовывод средств
«Ещё» → «Автовывод»: реквизиты, порог, остаток на балансе, минимум, лимит в сутки. Режимы:
- **выключен** — по умолчанию;
- **спрашивать** — бот присылает кнопку «Вывести»;
- **авто**.

Защита:
- в авторежиме бот выводит сам, только если точно знает доступный баланс, иначе всё равно спрашивает;
- одна попытка на заявку, без автоповторов;
- после любой ошибки автовывод встаёт на паузу до проверки;
- подтверждать вывод может только владелец, кнопка одноразовая;
- в уведомлениях видны только последние 4 цифры карты;
- все попытки записываются в историю.

> ⚠️ Формат запроса вывода на FunPay взят из открытой библиотеки FunPayAPI, проверить его на живом аккаунте я не мог. Для Playerok используется функция `request_withdrawal` из playerokapi, если она есть в установленной версии. **Сначала проверьте вывод в режиме «спрашивать» на минимальной сумме.**

Отдельно настраивается, ставить ли подпись в ответах, которые вы пишете сами из Telegram или мини-аппа. По подписи бот узнаёт свои сообщения.

Если имя в Telegram занято, поменяйте ссылку в мини-аппе («Ещё» → «О боте») или в Telegram («ℹ️ О боте»). Описание бота обновится само. Логотип для аватарки бота лежит в `assets/logo.png`: загрузите его в @BotFather → Edit Bot → Edit Botpic.

## Плагины
Папка `plugins/` изначально пустая. Установить плагин можно тремя способами: загрузить .py файл в мини-аппе, отправить файл боту в Telegram или вставить ссылку на GitHub. Поддерживаются:
- плагины **FunPay Cardinal** (`NAME`, `UUID`, `BIND_TO_*`);
- плагины **Castor**: один плагин сразу для двух площадок;
- модули **Playerok Universal**: только события, Telegram-роутеры aiogram не поддерживаются.

Как написать свой плагин — в [docs/PLUGINS.md](docs/PLUGINS.md).

## Структура
```
main.py               точка входа
castor/
  core.py             конфиг, хранилища, утилиты
  funpay.py           клиент FunPay
  playerok.py         мост к playerokapi
  services.py         циклы площадок
  app.py              ядро: сообщения, заказы, выдача
  features.py         отчёты, напоминания, бекапы, антифлуд, вебхуки
  proxy.py            прокси Telegram и автопереключение
  roles.py            роли и права
  stock.py            лоты без товара
  suppliers.py        API поставщиков
  finance.py          автовывод средств
  telegram_ui.py      админ-панель в Telegram
  web.py              API веб-панели и мини-аппа
  webapp/             мини-апп (HTML/CSS/JS)
  plugins.py, compat.py  плагины и совместимость с Cardinal
  cli.py              меню запуска и мастер
plugins/              ваши плагины
castor_data/             настройки, товары, статистика, логи, бекапы (создаётся сам)
```

## Важно
FunPay и Playerok не дают официального API. Бот работает так же, как браузер, и если площадка поменяет сайт, может понадобиться обновление. Сначала проверьте автовыдачу на недорогом тестовом лоте.
