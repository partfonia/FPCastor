# Castor — пакет владельца

Здесь всё, что нужно вам как автору: бот, сервер лицензий с магазином и инструменты для платных плагинов.

```
FPCastor_owner/
├─ bot/                  бот Castor целиком (то же, что на GitHub)
├─ license_server/       сервер лицензий + Telegram-магазин (звёзды)
├─ tools/make_paid_plugin.py   подготовка платного плагина к продаже
├─ paid_plugins/         шаблон платного плагина
└─ README_OWNER.md       эта инструкция
```

## 1. Бот (хостинг №1)
1. На Play2Go: Python 3.11+, файл запуска `main.py`.
2. Загрузите содержимое `bot/` + свою папку `castor_data` (настройки с компьютера) → «Старт».
3. 31 плагин уже встроен в бота: меню → «🧩 Плагины» (по подписке — раздел 3).

## 2. Сервер лицензий и магазин (хостинг №2)
1. В @BotFather создайте бота-магазин, скопируйте токен.
2. На втором сервере Play2Go: Python 3.11+, файл запуска `server.py`, загрузите содержимое `license_server/`.
3. «Старт» → сервер создаст `data/config.json` и напишет **ОТКРЫТЫЙ ключ**.
4. Заполните `data/config.json`: `shop_bot_token`, `owners` (ваш Telegram ID), `public_url` (`http://IP:ПОРТ` из панели),
   `products` (что продаёте). Перезапустите.
5. **Скачайте себе папку `data/`** и храните в надёжном месте. Это закрытый ключ и база покупателей:
   потеряете — все проданные ключи перестанут работать; отдадите кому-то — смогут делать ключи сами.

## 3. Подписка «Все плагины» — 50 ₽ в месяц
Все встроенные плагины бота (аренда, автоцена, коды с почты и т.д.) работают по одной подписке.
Пока подписка не настроена — всё бесплатно, так что бот работает уже сейчас.

1. Запустите сервер лицензий (раздел 2). В `data/config.json` уже есть товар `castor_plugins`:
   35 ⭐ (≈ 50–65 ₽ — зависит от того, как покупатель покупает звёзды) на 30 дней. Цену меняйте в `"stars"`.
2. На компьютере в папке `bot/` выполните (адрес и ОТКРЫТЫЙ ключ сервер печатает при запуске):
   ```
   python tools/setup_paywall.py --server http://IP:ПОРТ --pubkey ОТКРЫТЫЙ_КЛЮЧ --shop https://t.me/ваш_магазин_bot
   ```
   Или просто пришлите эти три значения — их впишут за вас.
3. Залейте обновлённого бота на GitHub и на свой хостинг.
4. Себе выдайте вечный ключ: в магазине `/grant ВАШ_ID castor_plugins 0`, введите его в боте → «🔑 Лицензии».

Покупатель видит в «🧩 Плагины» плашку «🔒 Плагины работают по подписке» с кнопками «Купить» и «Ввести ключ».
Плагины, которые человек ставит сам из файлов (например, ваш «Регистрация Rockstar»), подписка не трогает.
Отключить подписку: `python tools/setup_paywall.py --off`.

Честно о защите: бот открытый, на GitHub. Знающий программист может вырезать проверку в своей копии —
так у любого open-source. Подписка рассчитана на обычных продавцов, которым проще заплатить 50 ₽.

## 4. Платный плагин (отдельный, со своей ценой)
1. Возьмите `paid_plugins/paid_plugin_template.py`, переименуйте и напишите логику (каждое действие начинается
   с проверки `_licensed()`).
2. Положите скачанную `data/` в `license_server/data/` у себя на компьютере и выполните:
   ```
   pip install cryptography pyarmor
   python tools/make_paid_plugin.py мой_плагин.py ID_ТОВАРА http://IP:ПОРТ
   ```
   Скрипт подставит адрес, ключ и ID товара, запутает код (PyArmor) и положит готовый файл в `license_server/`.
3. Загрузите этот файл на сервер лицензий рядом с `server.py` и в `products` у товара укажите `"file": "имя.py"` —
   магазин сам пришлёт файл покупателю после оплаты.

## 5. Ключи себе
В магазине: `/grantall ВАШ_TELEGRAM_ID` — ключи на все платные плагины навсегда. Введите их в своём боте:
меню → «Далее» → «🔑 Лицензии».

## 6. Команды магазина
`/grant TG_ID ТОВАР ДНЕЙ` · `/grantall TG_ID [ДНЕЙ]` · `/keys [TG_ID]` · `/revoke КЛЮЧ` · `/reset КЛЮЧ` · `/stats`

Подробно — `bot/docs/PAID_PLUGINS.md`.
