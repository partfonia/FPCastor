# Платные плагины: как продавать

Схема простая:

```
Покупатель ── платит звёздами ──▶ ваш бот-магазин ──▶ выдаёт ключ CST-XXXX-…
                                         │
Бот покупателя ── «ключ верный?» ──▶ сервер лицензий ── подписанный ответ ──▶ плагин работает
```

- **Сервер лицензий и магазин** — `license_server/server.py`, один файл. Работает на вашем хостинге.
- **Ключ** привязан к Telegram ID покупателя и к одной установке бота. Передать ключ другу не выйдет:
  у друга другой Telegram ID и другая установка.
- **Ответ сервера подписан** (Ed25519). Плагин проверяет подпись открытым ключом, поэтому подделать сервер
  или «вечную лицензию» нельзя. Закрытый ключ лежит только у вас на сервере.
- **Без интернета** плагин работает до 72 часов по последней проверке, потом выключается.

## 1. Бот-магазин
1. В @BotFather создайте нового бота (например, `castor_shop_bot`) — это отдельный бот, не ваш Castor.
2. Подключать оплату отдельно не нужно: Telegram Stars работают у любого бота без договоров и эквайринга.
3. Скопируйте токен.

## 2. Сервер лицензий на хостинге (Play2Go или любой другой)
1. Создайте **отдельный** сервер на Python (Castor продолжает работать на своём): Python 3.11+, файл запуска `server.py`.
2. Загрузите в него содержимое папки `license_server/` (`server.py`, `requirements.txt`).
3. Нажмите «Старт». Сервер создаст `data/config.json` и напишет в консоли **ОТКРЫТЫЙ ключ** — сохраните его.
4. Откройте `data/config.json` в файловом менеджере панели и заполните:
   - `shop_bot_token` — токен магазина;
   - `owners` — ваш Telegram ID (узнать у @userinfobot), например `[123456789]`;
   - `public_url` — адрес сервера: `http://IP:ПОРТ` (IP и порт показаны в панели хостинга);
   - `products` — ваши плагины:
     ```json
     "products": {
       "autorobux": {"name": "AutoRobux", "description": "Выдача робуксов", "stars": 250, "days": 30, "file": "autorobux.py"}
     }
     ```
     `days: 0` — навсегда. `file` — файл плагина в папке сервера: магазин пришлёт его покупателю после оплаты.
5. Перезапустите. В консоли появится «Магазин запущен: @…».

> Папку `data/` никому не отдавайте и не выкладывайте: там закрытый ключ и база покупателей.
> Сделайте её копию себе — без неё все выданные ключи перестанут проверяться.

## 3. Платный плагин
1. Возьмите шаблон [`paid_plugin_template.py`](paid_plugin_template.py).
2. Заполните `PLUGIN_ID` (= ключ товара в `products`), `SERVER` (= `public_url`), `PUBKEY` (открытый ключ из консоли), `SHOP` (ссылка на магазин).
3. Напишите логику. Каждое действие плагина начинайте с `if not _licensed(): return False`.
4. Проверьте у себя: выдайте себе ключ командой `/grant ВАШ_ID ID_ПЛАГИНА 0` в магазине и введите его в боте
   (меню → «Далее» → «🔑 Лицензии»).

## 4. Защита кода перед продажей
Python читается как текст, поэтому перед продажей файл нужно запутать:

```
pip install pyarmor
pyarmor gen autorobux.py
```

В папке `dist/` появится защищённый `autorobux.py` и папка `pyarmor_runtime_…` — их и продавайте (папку класть рядом
в `plugins/`). Без PyArmor покупатель сможет удалить проверку ключа.

Самая надёжная защита — держать ценную часть на своём сервере: плагин отправляет туда запрос, сервер выполняет работу
(например, покупку у поставщика) только для действующего ключа. Тогда украденный файл бесполезен.

## 5. Команды магазина
| Кто | Команда | Что делает |
|---|---|---|
| покупатель | `/start` | каталог, оплата, «Мои ключи» |
| покупатель | `/reset КЛЮЧ` | сбросить привязку к установке (раз в сутки) — если перенёс бота |
| вы | `/grant TG_ID ПЛАГИН ДНЕЙ` | выдать или продлить ключ вручную (0 — навсегда) |
| вы | `/keys [TG_ID]` | список ключей |
| вы | `/revoke КЛЮЧ` | отозвать ключ |
| вы | `/stats` | продажи и активные ключи |

Продление: если покупатель оплатит плагин ещё раз, срок его ключа продлится, новый ключ не нужен.

## 6. Деньги
Звёзды копятся на балансе бота-магазина. Вывести их можно через @BotFather → ваш бот → Balance (Fragment, в TON)
или потратить на рекламу в Telegram. Если получаете доход в России — оформите самозанятость.
