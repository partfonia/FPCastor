# Сервер лицензий и магазин Castor

Один файл `server.py`: проверка ключей платных плагинов (подписанные ответы Ed25519) и Telegram-магазин
с оплатой звёздами. Полная инструкция — [docs/PAID_PLUGINS.md](../docs/PAID_PLUGINS.md).

Быстрый старт: загрузить `server.py` и `requirements.txt` на хостинг (Python 3.11+), запустить, заполнить
`data/config.json`, перезапустить. Папку `data/` не выкладывать никуда — там закрытый ключ.
